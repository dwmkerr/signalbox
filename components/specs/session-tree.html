Jumplist / RFC #61 / Session trees

Keep delegated work together

Follow a conversation from its main agent to the workers it launches, across Claude and Codex.

Interactive reference · scope below

Implemented scope: native Codex parent-thread records and Claude worker ownership hooks; collapse, search ancestry, unread navigation and missing-parent context in the macOS jumplist. New activity only, with no --json requirement. Cross-agent shell links, wrapper folding and the flat/tree switch below remain illustrative proposals. PID/PPID and titles do not establish session relationships.

Branch actions: Hide (⌃X) and Remove (⌃⌫ or ⌃⌦) act on the selected session and its recorded descendants, even when collapsed or filtered by search. Hidden or unavailable parent context rows support these actions on real sessions; they cannot jump, rename, or pin. Working sessions retain the existing Hide-as-acknowledge behavior. Unhide restores the hidden branch. See the jumplist contract.
